# Загрузка новых видео в Remotion

## Куда загружать исходники

Все новые исходные видео и аудио загружай в одну папку:

`remotion/public/videos/`

Ссылка на папку:
https://github.com/kot6119-dot/animated-spoon/tree/main/remotion/public/videos

## Правила имён

- Давай файлам понятные имена латиницей: `new-scene-01.mp4`, `forest-steps.wav`.
- Не используй имена старых роликов и не перезаписывай файлы, пока не проверено, что они больше не нужны.
- Готовый смонтированный MP4 не загружай сюда. Он сохраняется отдельно в артефактах сборки.

## Важный порядок работы

1. Сначала загрузи исходники в `public/videos/`.
2. Затем проверь точные имена файлов.
3. После этого подключи нужные файлы в `src/Root.jsx`.
4. Проверь композицию и только затем запускай рендер вручную через GitHub Actions → Render Remotion video → Run workflow.
5. Готовый iPhone MP4 забирай из раздела Artifacts завершённого запуска.

Загрузка исходников сама по себе рендер не запускает. Автоматического копирования готового ролика обратно в папку исходников нет.
