# Браузер Kaggle — эксперимент

Это отдельный эксперимент внутри репозитория `animated-spoon`. Он не меняет существующую панель генерации видео.

## Что умеет прототип

- Запускает отдельный Chromium через Playwright.
- Открывает Kaggle и страницы входа Google.
- Показывает снимок окна браузера.
- Позволяет кликать по снимку, вводить текст и нажимать несколько клавиш.
- Возвращает текст страницы для чтения и анализа.
- Хранит профиль браузера в постоянной папке, чтобы вход в Kaggle мог сохраняться между перезапусками.

## Важно

GitHub Pages хранит только статические файлы и не запускает Playwright. Для работы нужен отдельный сервер Node.js с установленным Chromium и постоянным диском. Этот репозиторий хранит исходный код сервера и интерфейса.

**Не добавляйте ключ доступа, cookies, пароли Kaggle или файлы профиля браузера в GitHub.** Задайте секрет `CONTROL_TOKEN` непосредственно в настройках хостинга. Используйте случайный ключ длиной не менее 24 символов. Для сохранения входа подключите постоянный диск и задайте `DATA_DIR` на этом диске.

## Запуск на сервере

Требования: Node.js 20+, системные зависимости Chromium для Playwright, постоянный диск.

```bash
cd browser-lab
npm install
npx playwright install --with-deps chromium
```

Задайте переменные окружения:

- `CONTROL_TOKEN` — случайный секретный ключ (не менее 24 символов).
- `DATA_DIR` — каталог на постоянном диске, например `/data`.
- `PORT` — порт, который предоставляет хостинг.

Затем:

```bash
npm start
```

Откройте адрес сервера в браузере, введите секретный ключ и нажмите «Открыть сайт».

## Первый тест

1. Откройте страницу браузерного сервиса.
2. Введите секретный ключ.
3. Откройте Kaggle.
4. Войдите в аккаунт самостоятельно через снимок браузера. Не отправляйте пароль в чат.
5. Нажмите «Прочитать текст страницы» и проверьте, что браузер видит страницу.
6. После этого можно испытывать переходы и кнопки Kaggle.

## Ограничения первой версии

- Это прототип, а не готовое подключение ChatGPT к браузеру.
- Разрешены только Kaggle и домены входа Google.
- Управление пока идёт через снимок экрана, координатные клики, клавиатуру и чтение текста.
- Сервис должен быть размещён на защищённом сервере. Не публикуйте его без секретного ключа и HTTPS.
- Некоторые действия Kaggle могут требовать ручного подтверждения или дополнительной проверки.
