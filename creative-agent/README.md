# Креативный сотрудник

Отдельный мини-сервис для внутренней работы: пользователь общается с главным ассистентом, а тот передаёт сотруднику творческие задачи и получает идеи.

## Что умеет
- Предлагать несколько концепций ролика по короткому описанию.
- Раскладывать идею на сцены, визуальные решения, звук и дикторский текст.
- Учитывать ограничения по длительности, бюджету и доступным инструментам.
- Отвечать по-русски и не запускать генерацию видео или внешние действия.

## Запуск
Требуется Python 3.10+.

```bash
cd creative-agent
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и задайте `OPENAI_API_KEY`. Затем:

```bash
python app.py
```

Откройте http://localhost:8080

## Настройки
- `OPENAI_API_KEY` — ключ API модели.
- `OPENAI_MODEL` — модель; по умолчанию `gpt-4.1-mini`.
- `PORT` — порт; по умолчанию `8080`.

Ключ хранится только в переменной окружения сервера. Не добавляйте настоящий ключ в GitHub.
